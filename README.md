# Лабораторная работа 10 (Вариант 10)

## Условие задачи
Составить программу, которая для заданной пользователем фигуры (ромб) предлагает меню выбора одной из операций:
1. рассчитать площадь;
2. вывести определение фигуры;
3. нарисовать фигуру.
Для каждой операции реализовать собственную функцию.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Вывести меню на экран.
3. Считать выбор пользователя.
4. Если выбрано «1» — запросить диагонали, вызвать `area_rhombus()`, вывести площадь.
5. Если выбрано «2» — вызвать `definition_rhombus()`.
6. Если выбрано «3» — запросить размер и символ, вызвать `draw_rhombus()`.
7. Если выбрано «0» — выйти из цикла.
8. Повторять, пока не выбран выход.
9. **Конец**
